# Ответы на вопросы — ПР20 (Express.js)

## 1. В чем преимущества Express.js по сравнению с чистым Node.js?
Express.js предоставляет готовые инструменты для маршрутизации, обработки middleware (промежуточных функций), парсинга тела запроса (JSON) и работы с параметрами URL. В чистом Node.js (модуль `http`) всё это приходится писать вручную, что делает код громоздким и сложным в поддержке.

## 2. Что такое middleware и каков порядок их выполнения?
Middleware — это функции с сигнатурой `(req, res, next)`, которые выполняются последовательно. Порядок выполнения строго соответствует порядку их подключения через `app.use()`. Вызов `next()` передает управление следующему middleware в стеке. Если `next()` не вызван, запрос «зависает».

## 3. Как организовать модульную структуру роутеров?
Создать отдельные файлы (например, `users.js`, `products.js`), в которых инициализируется `express.Router()`, определяются маршруты, и в конце файла делается `module.exports = router`. В главном файле `app.js` эти роутеры подключаются через `app.use('/api/users', usersRouter)`.

## 4. Какие методы роутинга поддерживает Express.js?
`app.get()`, `app.post()`, `app.put()`, `app.patch()`, `app.delete()`, `app.all()` (для всех методов) и `app.use()` (для middleware и подключения роутеров). Они используются для обработки соответствующих HTTP-запросов.

## 5. Как обрабатывать параметры URL и query-параметры?
- **Параметры URL** (например, `/users/:id`) доступны через `req.params.id`.
- **Query-параметры** (например, `/products?category=books`) доступны через `req.query.category`.

## 6. В чем разница между `app.use()` и `app.METHOD()`?
`app.use()` монтирует middleware или роутер, который будет обрабатывать запросы, начинающиеся с указанного пути (например, `/api/users`). `app.METHOD()` (где METHOD — это get, post и т.д.) обрабатывает запрос только с конкретным HTTP-методом и по точному пути.

## 7. Как организовать централизованную обработку ошибок?
Добавить в конец всех маршрутов middleware-обработчик ошибок, который принимает **4 аргумента**: `(err, req, res, next)`. Express автоматически распознает его и перенаправляет сюда все ошибки, вызванные через `next(err)`.

## 8. Что такое `router.param()` и для чего он используется?
Это middleware, привязанное к параметру маршрута (например, `id`). Оно выполняется каждый раз, когда в URL встречается этот параметр (например, при запросе `/users/5`). Используется для валидации параметра (например, проверки, что `id` — это число) или для загрузки данных пользователя из базы перед обработкой запроса.
