# Ответы на вопросы — ПР4 (Flexbox)

## 1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?

Основное свойство — `display: flex` (для блочного контейнера) или `display: inline-flex`.

После применения:
- Контейнер становится **flex-контейнером**.
- Все его **прямые дочерние элементы** становятся **flex-элементами**.
- Элементы выстраиваются в ряд по умолчанию (вдоль главной оси).
- Появляется возможность управлять их размером, порядком, выравниванием.

## 2. В чём разница между `justify-content` и `align-items`?

- `justify-content` — выравнивание вдоль **главной оси** (по умолчанию — горизонтально).
  Пример: `justify-content: center` — центрирует элементы по горизонтали.
- `align-items` — выравнивание вдоль **поперечной оси** (по умолчанию — вертикально).
  Пример: `align-items: center` — центрирует элементы по вертикали.

Оба нужны для центрирования: вместе дают идеальный центр.

## 3. Что делает `flex-direction` и какие значения принимает?

`flex-direction` задаёт **направление главной оси**. Значения:
- `row` (по умолчанию) — слева направо
- `row-reverse` — справа налево
- `column` — сверху вниз
- `column-reverse` — снизу вверх

Меняет не только направление, но и то, какая ось считается главной, а какая поперечной.

## 4. Значение трёх свойств в `flex: 1`

`flex: 1` — сокращение для:
- `flex-grow: 1` — элемент растягивается, занимая свободное место
- `flex-shrink: 1` — элемент может сжиматься при нехватке места
- `flex-basis: 0%` — базовая ширина = 0

В итоге: все элементы с `flex: 1` делят доступное пространство **поровну**.

## 5. Как работает `flex-wrap` и когда нужен?

`flex-wrap` управляет переносом элементов на новую строку:
- `nowrap` (по умолчанию) — всё в одну линию, элементы сжимаются
- `wrap` — перенос на новую строку, если не хватает места
- `wrap-reverse` — перенос в обратном направлении

Используется, когда элементов много и они должны переноситься, а не сжиматься. Пример — сетка карточек.

## 6. Чем отличается `align-content` от `align-items`?

- `align-items` — выравнивает элементы **внутри одной линии** по поперечной оси.
- `align-content` — выравнивает **целые линии** (ряды) относительно контейнера. Работает только если включён `flex-wrap: wrap` и элементов больше одной строки.

`align-items` нужен всегда; `align-content` — только для многострочных flex-контейнеров.

## 7. Как `order` влияет на отображение и где полезно?

`order` меняет **порядок отображения** flex-элементов без изменения HTML. По умолчанию `order: 0`, чем меньше значение — тем раньше элемент.

Полезно:
- Поменять местами блоки на мобильных (например, сайдбар после контента).
- Вывести важный элемент вперёд.
- Сделать визуальный редизайн без правки HTML.

## 8. Что такое главная и поперечная оси?

- **Главная ось (main axis)** — направление, в котором выстраиваются flex-элементы. Задаётся `flex-direction`.
- **Поперечная ось (cross axis)** — перпендикулярна главной.

Если `flex-direction: row`, главная ось — горизонтальная, поперечная — вертикальная.
Если `flex-direction: column`, главная — вертикальная, поперечная — горизонтальная.

Свойства `justify-*` работают по главной оси, `align-*` — по поперечной.

## 9. Как создать адаптивный макет без медиа-запросов?

С помощью:
- `flex-wrap: wrap` — элементы переносятся при нехватке места
- `flex: 1 1 250px` — базовый размер + возможность расти и сжиматься
- `min-width` / `max-width` — ограничения

Пример:
```css
.content {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}
.card {
    flex: 1 1 250px;
}
```


## 10. Преимущества `gap` вместо `margin` для промежутков

- Не нужно задавать отступы каждому элементу и компенсировать крайние.
- Не появляется лишний отступ по краям контейнера.
- Работает одинаково по обеим осям (и строкам, и столбцам).
- Код чище и понятнее: одно свойство вместо `margin-right`, `margin-bottom`, `:last-child { margin: 0 }`.
- Проще поддерживать: при переносе строк промежутки сохраняются автоматически.
