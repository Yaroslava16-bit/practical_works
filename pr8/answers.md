# Ответы на вопросы — ПР8 (Работа с макетом)

## 1. Какие инструменты графического редактора наиболее полезны для извлечения информации?

В Figma это панель **Inspect** (справа), где видны точные размеры, отступы, цвета (HEX) и шрифты. Также помогает зажать клавишу `Alt` и навести на элемент, чтобы увидеть расстояние до соседних блоков.

## 2. Как правильно организовать структуру CSS-переменных на основе данных из макета?

Разделить переменные по группам: цвета (`--color-primary`), типографика (`--font-size-lg`), отступы (`--spacing-md`), тени (`--shadow-sm`). Хранить их в отдельном файле `variables.css` и использовать через `var()`.

## 3. Какие метрики из макета наиболее критичны для точной верстки?

Ширина контейнера (например, 1200px), отступы между секциями (например, 80px), размеры шрифтов и межстрочные интервалы, а также цвета (HEX-коды) и радиусы скруглений.

## 4. Как определить систему сетки в макете и перенести ее в CSS Grid или Flexbox?

В Figma включить «Layout Grid» (клавиша `Shift + G`). Обычно это 12-колоночная сетка. В CSS ее можно реализовать через `display: grid; grid-template-columns: repeat(12, 1fr);` или через Flexbox.

## 5. Какие сложности возникают при переносе типографии из графического макета в веб-страницу?

Разные рендеринги шрифтов в браузерах, отсутствие нужного шрифта в веб-доступе, разница между единицами измерения в Figma (px) и адаптивным вебом (rem, em, vw).

## 6. Как обрабатывать адаптивность, когда в макете представлен только десктопный вариант?

Адаптивность продумывается самостоятельно по стандартным брейкпоинтам (1024px, 768px, 480px). Элементы перестраиваются: сетки становятся одноколоночными, меню — бургер-меню, шрифты уменьшаются через `clamp()` или медиа-запросы.

## 7. Какие инструменты браузера помогают сравнивать сверстанную страницу с оригинальным макетом?

В DevTools — режим адаптивного дизайна (Device Toolbar), инспектор для проверки отступов, вкладка Computed для анализа итоговых стилей, а также наложение картинки макета поверх страницы (через расширения).

## 8. Как правильно экспортировать изображения из графического редактора для веб-использования?

В Figma: выделить элемент → в панели справа внизу «Export» → выбрать формат (SVG для иконок, PNG/JPG для фото, WebP для оптимизации) → указать масштаб (1x, 2x) → нажать «Export».

## 9. Что делать, если в макете используются шрифты, которых нет в веб-доступе?

Заменить на похожие веб-безопасные шрифты (Google Fonts, например, Inter вместо SF Pro). Либо использовать `@font-face` и загрузить шрифт локально (если есть лицензия). Указать в отчете о замене.

## 10. Какие методологии помогают поддерживать соответствие между макетом и кодом при дальнейших изменениях?

Дизайн-системы (UI-киты), общие CSS-переменные (design tokens), автоматическая синхронизация через плагины (Figma to Code), а также регулярное code review и совместная работа дизайнера и разработчика.
