# Ответы на вопросы — ПР19 (Node.js сервер)

## 1. Что такое Node.js и в чем его преимущества для создания серверов?
Node.js — это среда выполнения JavaScript на стороне сервера. Его главные преимущества: асинхронная неблокирующая модель ввода-вывода (event loop), которая позволяет обрабатывать тысячи соединений одновременно без создания дополнительных потоков (что экономит память), высокая скорость работы (движок V8) и возможность использовать JavaScript на клиенте и сервере.

## 2. Как создать простой HTTP-сервер в Node.js?
Нужно подключить встроенный модуль `http`, создать сервер с помощью `http.createServer((req, res) => {...})` и вызвать метод `.listen(port)`. Внутри коллбэка обрабатываются запросы и отправляются ответы через `res.end()`.

## 3. В чем разница между методами GET, POST, PUT и DELETE?
- **GET** — получение данных (не изменяет сервер).
- **POST** — создание нового ресурса (данные передаются в теле запроса).
- **PUT** — полное обновление существующего ресурса.
- **DELETE** — удаление ресурса.

## 4. Что такое middleware и для чего оно используется?
Middleware (промежуточное ПО) — это функции, которые выполняются последовательно до того, как запрос дойдет до финального обработчика (маршрута). Они используются для логирования, парсинга тела запроса (JSON), проверки авторизации, обслуживания статических файлов или обработки CORS.

## 5. Как обрабатывать различные HTTP-методы для одного URL?
Внутри сервера проверяется `req.method` (например, `'GET'` или `'POST'`) вместе с `pathname`. В зависимости от их комбинации вызывается соответствующая функция-обработчик.

## 6. Что такое CORS и зачем нужны соответствующие заголовки?
CORS (Cross-Origin Resource Sharing) — это механизм безопасности браузера, который запрещает запросы с одного домена (порта) к другому. Чтобы разрешить тестирование клиента (например, с `localhost:5500` на сервер `localhost:3000`), сервер должен отправлять заголовки `Access-Control-Allow-Origin: *` и разрешать методы/заголовки.

## 7. Как организовать чтение тела POST-запроса в Node.js?
В Node.js тело запроса приходит в виде потока данных (stream). Нужно подписаться на событие `data` (`req.on('data', chunk => body += chunk)`), чтобы собрать все части в строку, а затем на событие `end` — где эту строку можно преобразовать через `JSON.parse()`.
