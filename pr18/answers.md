# Ответы на вопросы — ПР18 (React Router)

## 1. В чем разница между Link и NavLink в React Router?
`Link` используется для обычной навигации без перезагрузки страницы. `NavLink` — это специальная версия `Link`, которая автоматически добавляет класс `active` (или позволяет стилизовать элемент), когда текущий URL совпадает с его маршрутом. Это удобно для подсветки активного пункта меню.

## 2. Как получить параметры из URL в компоненте?
С помощью хука `useParams()`. Он возвращает объект с параметрами, определенными в `Route` (например, если маршрут `path="/products/:id"`, то `const { id } = useParams()` вернет ID из URL).

## 3. Что такое программная навигация и как ее реализовать?
Это переход на другую страницу, вызываемый не кликом по ссылке, а кодом (например, после отправки формы или успешного логина). Для этого используется хук `useNavigate()`:
`const navigate = useNavigate(); navigate('/success');`

## 4. Как передать данные между маршрутами?
1. Через параметры URL (`/user/:id`) и `useParams()`.
2. Через query-параметры (`/search?q=react`) и `useSearchParams()`.
3. Через объект `state` в функции навигации: `navigate('/path', { state: { data } })` и чтение через `useLocation().state`.

## 5. Что делает компонент Routes?
`Routes` — это контейнер, который оборачивает все маршруты (`Route`). Он анализирует текущий URL и рендерит только тот компонент, путь которого совпадает с URL. (В React Router v5 вместо него использовался `Switch`).

## 6. Как создать защищённый маршрут?
Создается компонент-обертка (ProtectedRoute), который проверяет условия (например, авторизован ли пользователь). Если нет — перенаправляет на страницу логина через `<Navigate to="/login" />`, если да — рендерит переданный компонент через `children` или `<Outlet />`.

## 7. В чем разница между useNavigate и redirect?
`useNavigate` — это хук, который используется внутри React-компонентов (функциональных) для программного перехода. `redirect` — это функция, используемая в загрузчиках (loaders) и экшенах (actions) в новых версиях React Router (Data APIs), она возвращает объект ответа, а не вызывается напрямую в компоненте.
