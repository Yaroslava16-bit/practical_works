# Ответы на вопросы — ПР6 (Адаптивная верстка)

## 1. Что такое Viewport meta tag и почему он важен?

`<meta name="viewport" content="width=device-width, initial-scale=1.0">` сообщает браузеру, что ширина страницы равна ширине экрана устройства. Без него мобильные браузеры показывают страницу в «настольном» масштабе, и адаптивность не работает.

## 2. Какие основные подходы к адаптивным макетам вы использовали?

Использовал Responsive — гибкие контейнеры, медиа-запросы и относительные единицы. Также элементы Fluid (проценты, `clamp`) и Adaptive (фиксированные брейкпоинты).

## 3. Как работает Mobile First и в чём его преимущества?

Mobile First — сначала пишем стили для мобильных, потом расширяем через `min-width`. Преимущества: меньше кода, быстрее загрузка на мобильных, проще масштабировать вверх.

## 4. Какие единицы измерения предпочтительны и почему?

`rem` — для шрифтов и отступов, `%` — для ширины контейнеров, `vw/vh` — для элементов во весь экран, `clamp()` — для адаптивной типографики.

## 5. Как `clamp()` помогает создавать адаптивную типографику?

`clamp(минимум, предпочтительно, максимум)` — задаёт диапазон: шрифт не меньше минимума и не больше максимума, а между ними плавно меняется. Пример: `font-size: clamp(1.5rem, 5vw, 2.5rem)`.

## 6. Какие брейкпоинты вы использовали и как определили?

- 1024px — планшеты
- 768px — мобильные
- 480px — маленькие мобильные

Значения взяты по типовым размерам устройств и по стандартам Bootstrap/Tailwind.

## 7. Как медиа-запросы помогают создавать адаптивные стили?

`@media` применяет CSS-правила при определённых условиях — например, `@media (max-width: 768px) { .nav-menu { display: none; } }`. Так один и тот же HTML выглядит по-разному на разных экранах.

## 8. Разница между `max-width` и `min-width` в медиа-запросах

`max-width: 768px` — стили применяются, если ширина меньше или равна 768px (Desktop First). `min-width: 768px` — если больше или равна (Mobile First). Предпочтительнее `min-width`.

## 9. Как сделать изображения адаптивными?

Через CSS `img { max-width: 100%; height: auto; }` — картинка не выходит за пределы контейнера и сохраняет пропорции. Дополнительно — `srcset` и `sizes` для разных разрешений.

## 10. Какие инструменты браузера помогают тестировать адаптивный дизайн?

В DevTools — Device Toolbar (Cmd + Shift + M в Chrome): эмуляция устройств, разрешений и ориентаций. Позволяет быстро проверить брейкпоинты, мобильное меню и изображения.
