# Ответы на вопросы — ПР9 (JavaScript: базовые алгоритмы)

## 1. В чем разница между временной сложностью O(n) и O(n²)?
O(n) — линейная сложность: время растет пропорционально количеству элементов (например, поиск максимума в массиве). O(n²) — квадратичная: время растет пропорционально квадрату элементов (например, пузырьковая сортировка с вложенными циклами).

## 2. Как работает алгоритм бинарного поиска и почему его сложность O(log n)?
Он делит отсортированный массив пополам на каждом шаге, сравнивая средний элемент с искомым. Так как количество элементов уменьшается вдвое каждый раз, требуется около log₂(n) шагов. Отсюда сложность O(log n).

## 3. Какие преимущества и недостатки у пузырьковой сортировки?
Преимущества: простота реализации, легкость понимания, работает на месте (без выделения памяти). Недостатки: высокая сложность O(n²), неэффективна для больших массивов (лучше использовать быструю или слиянием).

## 4. Как можно оптимизировать функцию проверки на простое число?
Проверять делители только до корня из числа (`i * i <= n`). Пропускать четные числа после проверки на 2 (шаг цикла `i += 2`). Использовать вероятностные тесты (Миллер-Рабин) для очень больших чисел.

## 5. В чем разница между рекурсивной и итеративной реализацией Фибоначчи?
Рекурсивная — элегантная, но медленная O(2ⁿ) из-за повторных вычислений (без мемоизации). Итеративная — использует цикл, работает за O(n) и потребляет меньше памяти (нет переполнения стека).

## 6. Какие методы отладки вы использовали?
`console.log()` для вывода промежуточных значений, пошаговое выполнение в DevTools (Sources/Breakpoints), встроенные тесты (наши функции `runTest`), проверка edge cases (пустые массивы, отрицательные числа).

## 7. Как работает алгоритм Евклида для нахождения НОД?
НОД(a, b) = НОД(b, a % b). Мы заменяем большее число на остаток от деления, пока одно из чисел не станет нулем. Эффективен, так как остаток быстро уменьшается, сложность O(log(min(a, b))).

## 8. Какие edge cases нужно учитывать при работе с массивами?
Пустой массив (возвращать null или 0), массив из одного элемента, неотсортированный массив для бинарного поиска (нужна предварительная сортировка), массивы с дубликатами и `NaN`.

## 9. Как улучшить функцию удаления дубликатов для больших массивов?
Использовать `Set` (`[...new Set(arr)]`) — работает за O(n). Или создать объект-хэш (`{}`) для отслеживания уже встреченных элементов. Текущая реализация через `includes` имеет сложность O(n²).

## 10. Какие принципы чистого кода вы применили?
Понятные имена переменных и функций (`isPrime`, `findMax`), отсутствие дублирования кода, короткие функции (одна задача — одна функция), комментарии со сложностью, обработка edge cases (пустые массивы, отрицательные числа).
