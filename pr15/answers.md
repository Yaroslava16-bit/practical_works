# Ответы на вопросы — ПР15 (React компоненты)

## 1. В чем разница между функциональными и классовыми компонентами?
Классовые компоненты используют классы ES6, имеют методы жизненного цикла (`componentDidMount` и т.д.) и управляют состоянием через `this.state`. Функциональные компоненты — это обычные функции, которые используют хуки (`useState`, `useEffect`) для состояния и побочных эффектов. Сейчас стандартом считаются функциональные компоненты, так как они короче и быстрее.

## 2. Что такое props и state?
`props` (свойства) — это данные, передаваемые от родительского компонента к дочернему. Они доступны только для чтения (нельзя изменять). `state` — это внутреннее состояние компонента, которое он контролирует сам и может изменять через `setState` (или сеттер хука). Изменение стейта вызывает перерендер.

## 3. Как работает поднятие состояния (lifting state up)?
Когда двум компонентам нужно синхронизировать данные, состояние переносится в их ближайший общий родитель. Родитель передает данные вниз через `props` и передает функции-коллбэки для изменения этого состояния.

## 4. Какие методы жизненного цикла вы знаете?
В классовых компонентах: `componentDidMount` (после монтирования), `componentDidUpdate` (после обновления), `componentWillUnmount` (перед удалением, используется для очистки таймеров/слушателей), `shouldComponentUpdate` (оптимизация).

## 5. Как работают хуки useState и useEffect? Какие правила?
`useState` возвращает массив из текущего значения и функции для его обновления. `useEffect` выполняет побочные эффекты (запросы, подписки) после рендера. Правила: хуки можно вызывать только на верхнем уровне компонента (не внутри условий или циклов) и только из React-компонентов или других хуков.

## 6. Что такое ключи (keys) в React?
`key` — это уникальный строковый атрибут, который помогает React отслеживать, какие элементы списка были добавлены, изменены или удалены. Без ключей React перерисовывает весь список целиком, что бьет по производительности.

## 7. Как обрабатывать события в React?
В React события пишутся в camelCase (`onClick` вместо `onclick`), и в качестве обработчика передается функция, а не строка. React использует SyntheticEvent (синтетические события) — обертку над нативными событиями для кроссбраузерности.

## 8. Что такое управляемые и неуправляемые компоненты?
Управляемый компонент — это форма, где значение поля (`value`) контролируется состоянием React, и при вводе вызывается `onChange`. Неуправляемый — где данные хранятся в самом DOM, а доступ к ним получают через `useRef` или `document.getElementById`.

## 9. Как работает контекст (Context) и когда его использовать?
Context позволяет передавать данные (например, тему или язык) через дерево компонентов, не передавая их вручную через `props` на каждом уровне. Используется для глобальных данных.

## 10. Преимущества кастомных хуков?
Кастомные хуки (начинаются с `use`) позволяют выносить повторяющуюся логику (например, работу с API или `localStorage`) в отдельную функцию, которую можно переиспользовать в разных компонентах, делая код чище.
