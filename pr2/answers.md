# Ответы на вопросы - ПР2 (Семантическая HTML-разметка)

## 1. Чем семантическая верстка отличается от несемантической и почему она важна?

Семантическая верстка использует теги по смыслу (header, nav, article, section), а несемантическая — универсальные div и span для всего. Семантическая важна, потому что:
- улучшает SEO — поисковики понимают структуру;
- повышает доступность — скринридеры корректно озвучивают;
- делает код читаемым и поддерживаемым.

## 2. В каких случаях <article> вместо <section>?

<article> — для самостоятельного контента, который можно вырвать из контекста (пост блога, новость, карточка товара). <section> — для тематического раздела внутри чего-то.

В моей работе: статьи про рок, джаз и электронику — это <article> (самостоятельные материалы). «О нашем портале» — <section>, потому что это часть общей страницы.

## 3. Для чего <header> и <footer>, могут ли использоваться несколько раз?

<header> — вводная часть блока (заголовок, навигация, логотип). <footer> — завершающая (автор, копирайт, контакты).

Да, могут использоваться несколько раз: у страницы в целом, у каждого <article>, у <section>. В моей работе у каждой статьи свой <header> и <footer>.

## 4. Тег для основного контента — <main>. Почему не <div>?

<main> семантически обозначает главное содержимое страницы, уникален (должен быть один), помогает скринридерам и поисковикам пропустить навигацию и перейти сразу к сути. <div> не несёт смысла.

## 5. Разница между <nav> и обычным списком ссылок?

<nav> — семантический тег для основных навигационных блоков (меню, хлебные крошки). Обычный <ul> со ссылками — для ссылок внутри текста или футера.

<nav> обязательно использовать для основной навигации, потому что это ключевой элемент доступности.

## 6. Для чего атрибут datetime в <time>?

datetime содержит машиночитаемый формат даты (2024-04-10). Это важно для поисковиков, календарей, микроданных. Человек видит «10 апреля 2024», а машина — точную дату.

## 7. Преимущества <figure> и <figcaption>?

<figure> группирует изображение и подпись в единый блок. <figcaption> — сама подпись. Это позволяет стилизовать их как единое целое, семантически связать картинку с описанием. Простой <img> без обёртки такой связи не даёт.

## 8. Когда использовать <aside>?

Для контента, косвенно связанного с основным: боковые панели, реклама, ссылки, цитаты, виджеты. В моей работе <aside> содержит «Популярные жанры» — дополнительная навигация, не основная.

## 9. Как семантика влияет на SEO и доступность?

SEO: поисковики лучше понимают структуру, ранжируют контент точнее. Доступность: скринридеры корректно озвучивают блоки, пользователи с ограничениями могут быстро перемещаться по разделам.

## 10. Какие теги использовал и как они помогают?

Использовал: header, nav, main, article, section, aside, footer, figure, figcaption, time, details, summary, address.

Они помогают пользователям (понятная навигация), поисковикам (контекст), разработчикам (читаемый код).
